# Xerxes — مدیریت و برنامه‌ریزی (نسخهٔ ۳)

وب‌اپ نصب‌شدنی (PWA) برای مدیریت کار، پروژه و رویداد؛ داده در Google Sheet شخصی، رویدادها در Google Calendar.

## ساختار

| مسیر | نقش |
|---|---|
| `index.html` · `app.css` · `app.js` | خود برنامه |
| `manifest.webmanifest` · `sw.js` | نصب و کار آفلاین |
| `icons/` | آیکون (SVG منبع + PNG) |
| `fonts/` · `vendor/` | فونت وزیرمتن (OFL) و کتابخانهٔ QR (MIT) |
| `apps-script/Code.gs` | بک‌اند؛ در Apps Script کپی می‌شود، **نه** در GitHub |

## ارتقا از نسخهٔ قبل

### ۱. بک‌اند
1. در Apps Script محتوای `Code.gs` را با `apps-script/Code.gs` جایگزین کن و ذخیره کن.
2. Project Settings (چرخ‌دنده) ← Time zone: **(GMT+03:30) Tehran**.
3. تابع `setupToken` را Run کن. این کار شیت‌های `domains` و `events` را می‌سازد و سه حوزهٔ فعلی را با بودجه‌هایشان منتقل می‌کند. کلید دسترسی عوض نمی‌شود.
4. تابع `setupCalendar` را Run کن ← مجوز Google Calendar را تأیید کن. تقویم جداگانه‌ای به نام «Xerxes» ساخته می‌شود.
5. Deploy › Manage deployments ← ویرایش (مداد) ← Version: **New version** ← Deploy. آدرس `/exec` تغییر نمی‌کند.

### ۲. برنامه (GitHub)
1. در مخزن، همهٔ فایل‌های این پوشه را آپلود کن و جایگزین کن (به‌جز `apps-script/`). فایل‌های `app.css` و `app.js` تازه‌اند.
2. پس از یکی‌دو دقیقه برنامه را یک بار باز کن و ببند؛ نسخهٔ تازه جایگزین می‌شود. اتصال قبلی حفظ می‌شود.
3. نام و آیکون روی صفحهٔ اصلی گوشی فقط با حذف و نصب دوبارهٔ میان‌بر عوض می‌شود.

## نصب تازه
همان مراحل نسخهٔ قبل: شیت جدید ← Code.gs ← `setupToken` ← `setupCalendar` ← Deploy (Execute as: Me · Who has access: Anyone) ← آپلود به GitHub Pages ← وارد کردن آدرس و کلید ← نصب. اتصال گوشی: تنظیمات ← QR.

## یادآوری‌ها
یادآوری روی گوشی از طریق اپ **Google Calendar** می‌رسد (تقویم «Xerxes» را در آن فعال نگه دار). خود برنامه فقط وقتی باز است، رویدادهای نزدیک را در صفحهٔ خانه نشان می‌دهد.

- تکرار هفتگی در تقویم گوگل یک سری تکرارشونده است.
- تکرار ماهانه/سالانه بر مبنای **تاریخ شمسی** است؛ چون تقویم گوگل تکرار شمسی ندارد، ۱۲ رخداد ماهانه یا ۱۰ رخداد سالانهٔ بعدی جداگانه ساخته می‌شود. هر بار که رویداد را ویرایش و ذخیره کنی، دوباره ساخته می‌شوند.
- همگام‌سازی یک‌طرفه است: تغییر در Google Calendar به برنامه برنمی‌گردد.

## امنیت
کد اتصال و کلید دسترسی حکم رمز عبور دارند. اگر لو رفت: `rotateToken` را Run کن و دستگاه‌ها را دوباره وصل کن.
