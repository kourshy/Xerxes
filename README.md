# Xerxes — مدیریت و برنامه‌ریزی (نسخهٔ ۵)

وب‌اپ نصب‌شدنی (PWA) برای مدیریت سبد پروژه‌های تیم، با لایهٔ کارهای شخصی؛ داده در Google Sheet شخصی، یادآورها در Google Calendar.

## تغییرات نسخهٔ ۵ (مرحلهٔ اول بازطراحی)

| بخش | چه چیزی |
|---|---|
| ناوبری ریتم‌محور | امروز · هفته · پروژه‌ها · افراد · شخصی؛ صندوق و حوزه‌ها در منو |
| پروژه‌ها | پنج نما روی یک داده: نمای کلی (نمودارها) · کارت‌ها · بُرد مرحله‌ای · نقشهٔ درختی · فهرست و آرشیو |
| ابرپروژه | هر پروژه می‌تواند «ابرپروژه» داشته باشد؛ در کارت‌ها گروه‌بندی و در نقشه شاخه می‌شود |
| پایپ‌لاین | مرحلهٔ هر پروژه (ایده / تعریف / اجرا / تحویل) با کشیدن کارت در بُرد عوض می‌شود |
| شخصی | بُرد با سه ستون‌بندی (وضعیت / زمان / پروژه)؛ کشیدن کارت‌ها و جابه‌جایی ستون پروژه‌ها؛ گام‌ها مستقیم روی بُرد |
| صفحهٔ هر فرد | پروژه‌ها، گام‌های باز، سپردن کار مستقیم به همان فرد |
| امروز | نیازمند توجه + پیگیری کارهای سپرده‌شده |
| لینک مستقیم | هر پروژه `#p/…` و هر فرد `#u/…`؛ دکمهٔ «بازگشت» مرورگر کار می‌کند |
| میان‌برها | Ctrl/⌘+K یا `/` جستجو و فرمان · N کار · P پروژه · ۱ تا ۵ صفحه‌ها · G سپس حرف · `[` `]` نما · `?` راهنما |
| کشیدن و رها کردن | با موس و لمس (روی موبایل: انگشت را لحظه‌ای نگه دار، بعد بکش) |

## ارتقا از نسخهٔ ۴ (داده‌ها حفظ می‌شوند)
1. `Code.gs` را با `apps-script/Code.gs` جایگزین کن، ذخیره کن، `setupToken` را Run کن (ستون‌های `parent`، `stage` و `porder` به شیت `projects` اضافه می‌شوند).
2. Deploy › Manage deployments ← ویرایش ← Version: **New version** ← Deploy.
3. فایل‌های برنامه را در مخزن جایگزین کن؛ برنامه را یک بار ببند و باز کن.
4. یادآورها تغییری ندارند؛ اگر `installReminders` را قبلاً اجرا کرده‌ای، لازم نیست دوباره اجرا شود.

پروژه‌های موجود بدون مرحله، در مرحلهٔ «اجرا» قرار می‌گیرند.

## تغییرات نسخهٔ ۴ (برای سابقه)

| بخش | چه چیزی |
|---|---|
| سبد (صفحهٔ اول) | چهار شاخص، توزیع سلامت پروژه‌ها، فهرست «نیازمند توجه»، نمودار پیشرفت در برابر زمان، خط زمانی |
| پروژه‌های تیم | فهرست با فیلتر مسئول و وضعیت، آرشیو با جستجو |
| صفحهٔ پروژه | ارزیابی سریع (پیشرفت + سلامت + یک خط یادداشت)، روند پیشرفت، گام‌ها با انجام‌دهنده، شناسنامه، تاریخچه |
| افراد | هر نفر: پروژه‌هایی که مسئول آن‌هاست، گام‌های باز، یادداشت خصوصی |
| امروزِ من | فقط کارهای خودت از همهٔ حوزه‌ها |
| شخصی | حوزه‌های غیرتیمی؛ قاعدهٔ گام اتمی فقط اینجا فعال است |
| بازبینی هفتگی | ارزیابی پروژه‌به‌پروژه + بخش شخصی قبلی |
| ثبت سریع | `#پروژه` · `@نفر` · `!امروز` · `!فردا` · عدد + «د» = دقیقه |
| یادآور | ایمیل روزانه حدود ۹:۳۰ (شنبه تا پنجشنبه) + رویداد تکرارشونده در تقویم «Xerxes» |

## ارتقا از نسخهٔ ۳ (داده‌ها حفظ می‌شوند)

### ۱. بک‌اند (Apps Script)
1. محتوای `Code.gs` را با `apps-script/Code.gs` جایگزین کن و ذخیره کن.
2. تابع `setupToken` را Run کن. شیت‌های `people` و `updates` و ستون‌های تازه ساخته می‌شوند؛ حوزهٔ «R&D هلدینگ» تیمی و بقیه شخصی علامت می‌خورند. کلید دسترسی عوض نمی‌شود.
3. Deploy › Manage deployments ← ویرایش (مداد) ← Version: **New version** ← Deploy. آدرس `/exec` تغییر نمی‌کند.

### ۲. برنامه (GitHub)
1. همهٔ فایل‌های این پوشه (به‌جز `apps-script/`) را در مخزن جایگزین کن.
2. برنامه را یک بار باز کن، ببند و دوباره باز کن تا نسخهٔ تازه جایگزین شود. با اولین باز شدن، آدرس برنامه در Sheet ثبت می‌شود (برای لینک داخل ایمیل و تقویم).

### ۳. یادآورها
1. بعد از گام ۲، تابع `installReminders` را Run کن و مجوزها را تأیید کن.
2. در اپ Google Calendar گوشی، تقویم «Xerxes» را فعال نگه دار تا نوتیفیکیشن برسد.
3. ساعت یادآور در بالای `Code.gs` است (`REMIND_HOUR` و `REMIND_MIN`). بعد از تغییر، `installReminders` را دوباره Run کن.

تریگر زمانی Apps Script دقیقه‌ای نیست و ممکن است تا حدود ۱۵ دقیقه جابه‌جا اجرا شود. جمعه ایمیل ارسال نمی‌شود.

## اولین استفاده
1. «افراد» ← اعضای تیم را اضافه کن.
2. «سبد» ← «پروژه»: نام، مسئول، شروع و ددلاین. بقیهٔ شناسنامه اختیاری است.
3. برای هر پروژه یک ارزیابی اول ثبت کن. از این به بعد، شنبه‌ها در «بازبینی هفتگی».

## منطق شاخص‌ها
- **پیشرفت:** درصدی که خودت در ارزیابی وارد می‌کنی (گام‌ها در آن دخالتی ندارند).
- **پیشرفت مورد انتظار:** سهم زمان سپری‌شده از شروع تا ددلاین. فقط معیار مقایسه است، نه هدف.
- **عقب از زمان:** پیشرفت بیش از ۲۰ واحد کمتر از انتظار.
- **ارزیابی کهنه:** آخرین ارزیابی قدیمی‌تر از آستانهٔ تنظیمات (پیش‌فرض ۷ روز).
- **نیازمند توجه:** هر پروژهٔ فعال با دست‌کم یکی از این‌ها: در خطر، ارزیابی کهنه یا نشده، ددلاین گذشته یا کمتر از ۱۴ روز مانده، عقب از زمان.

## ساختار

| مسیر | نقش |
|---|---|
| `index.html` · `app.css` · `app.js` | خود برنامه |
| `manifest.webmanifest` · `sw.js` | نصب و کار آفلاین |
| `icons/` | آیکون (SVG منبع + PNG) |
| `fonts/` · `vendor/` | فونت وزیرمتن (OFL) و کتابخانهٔ QR (MIT) |
| `apps-script/Code.gs` | بک‌اند؛ در Apps Script کپی می‌شود، **نه** در GitHub |

## نصب تازه
شیت جدید ← Code.gs ← `setupToken` ← `setupCalendar` ← Deploy (Execute as: Me · Who has access: Anyone) ← آپلود به GitHub Pages ← وارد کردن آدرس و کلید ← باز کردن برنامه ← `installReminders` ← نصب روی گوشی (تنظیمات ← QR).

## رویدادها
- تکرار هفتگی در تقویم گوگل یک سری تکرارشونده است.
- تکرار ماهانه/سالانه بر مبنای **تاریخ شمسی** است؛ ۱۲ رخداد ماهانه یا ۱۰ رخداد سالانهٔ بعدی جداگانه ساخته می‌شود.
- همگام‌سازی یک‌طرفه است: تغییر در Google Calendar به برنامه برنمی‌گردد.

## امنیت
کد اتصال و کلید دسترسی حکم رمز عبور دارند. اگر لو رفت: `rotateToken` را Run کن و دستگاه‌ها را دوباره وصل کن. یادداشت‌های خصوصی افراد در همان Google Sheet ذخیره می‌شوند؛ دسترسی به Sheet را محدود نگه دار.
